## How it was taken
By five read-only sub-agents of the session `JH 7 · registro de fallas y reglas`, one per layer,
each given the same brief: the places that act (A1: `AGENTS.md`, the skills' texts, the
template, every constant, message and usage text of the code), the roadmap (A2), the feature
documents (A3, with the tips of the unmerged branches of the live sessions), what is installed
on the machine against its source (B), and the agents' memory notes with the orchestrator's
relief file (CD). The repository was read at `main` `51a24db`.

What is true, when two places differed, in this order: his latest words, what the code on `main`
does, `AGENTS.md`, the roadmap, a feature document.

A finding is a place a reader would take as in force today that says something no longer true.
Its kind is `acts` (code, a message, `AGENTS.md`, a skill or a template), `in force` (a
present-tense statement of a document or of a memory note), or `dated record` (an entry of its
day that is written so that it is read as the present). An entry of a `## Progress` section that
says what was true on its day is not a finding.

The owner of an item is who may correct it: the session that owns the file (`JH 5`, `JH 6`,
`JH 7`), `him` for the wording of `AGENTS.md` and for his memory notes, `orchestrator` for what
is installed and for its relief file. Paths outside the repository are of his machine.

## What this list is worth
- Each item is the claim of the reader that found it, with the text it quotes and its source.
  The session that corrects an item reads the place first; an item that turns out wrong is
  checked off with the word "wrong" and the reason.
- Not read by any layer: the test files, `evals/`, the transcripts, GitHub, the bodies of the
  `## Progress` sections (read only around search hits), about 150 of the relief file's 249
  lines beyond their first 170 characters, and the persistent memory kept by engram.
- A rule that is stale in the same words in a place no search reached is not here. The count is
  a floor.
- The same rule is named in slightly different words by different layers; the name after the
  place is the reader's.
